# Amazon Clone

A frontend clone of the Amazon homepage built using **HTML5** and **CSS3**. This project replicates the layout and visual design of the Amazon website while focusing on responsive web design and clean, semantic code.

## Features

* 🛒 Amazon-inspired homepage layout
* 📱 Responsive design for different screen sizes
* 🔍 Navigation bar with search section
* 📦 Product categories and promotional sections
* 🖼️ Hero banner and product cards
* 🦶 Footer similar to the original website
* 🎨 Clean and organized UI using only HTML and CSS

## Technologies Used

* HTML5
* CSS3

## Project Purpose

This project was developed to strengthen my frontend development skills by recreating the user interface of a popular e-commerce website. It demonstrates proficiency in HTML, CSS, responsive layouts, Flexbox, and CSS styling.

> **Note:** This is a frontend-only project created for educational purposes. It does not include JavaScript functionality, backend services, user authentication, shopping cart, or payment integration.
